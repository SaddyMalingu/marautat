# Wave 1 Execution Checklist

## Scope
Targets: Ventura, Sitefire, Lab0, CharacterQuilt, AgentPhone
Current status: spec_ready

## Daily Build Checklist
- Confirm one owner per target for today.
- Implement at least one API stub endpoint per target.
- Implement at least one UI state transition per target.
- Run target eval cases and record pass/fail.
- Capture one screenshot or short clip for demo evidence.
- Update backlog status and blockers by end of day.

## Definition of demo_ready
- API stubs respond with documented schema.
- UI states can be demonstrated end-to-end.
- Eval metrics run and produce numeric output.
- 3-minute demo flow recorded or rehearsed.
- Outreach message includes demo artifact link.

## Status Transition Rules
- spec_ready -> demo_ready: all definition-of-done items met.
- demo_ready -> sent: outreach sent with demo link.
- sent -> response: target replies or meeting booked.

## Blocker Protocol
- If blocked >24h: reduce scope, preserve demo storyline, and ship a smaller but complete proof.
- If blocked >48h: switch to next highest-priority target while documenting unresolved risk.
